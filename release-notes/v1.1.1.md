# v1.1.1 — Linux QML 清晰度修复

修复 Linux/Quickshell 版立绘发虚:Qt/GPU 直接把 610px 源图缩小到 170px 时,
缩放质量不如 Chromium。现在按显示尺寸和屏幕 DPR 选择 Lanczos 预缩放立绘
(`assets/scaled/`),正常大小基本是 1:1 贴图。

## 变更

- 新增 `assets/scaled/`(10 档尺寸)与 `tools/gen-scaled.sh`
- QML 根据 `scale × 屏幕 DPR` 自动选最接近的一档,预缩放图缺失时回退原图
- `model.sh list` 自动排除预缩放变体
- Windows 便携包一并重建(功能与 v1.1.0 相同;Windows 由 Chromium 缩放,不需要预缩放图)
